Synchro Recettes Inpulse → Notion

Chaque nuit, le catalogue de recettes actives d'Inpulse est poussé dans une base Notion, une page par recette. Objectif : que la liste de choix des fiches techniques d'emballage reste juste sans que personne la recopie.

Le principe

La fonction lit /public/v2/products sur l'API Inpulse, ne garde que les entrées entityType: "recipe" en statut active qui ont un prix et un coût matière, puis écrit une page Notion par recette.

  • La clé de rapprochement est la colonne texte « ID Inpulse ». C'est elle qui rend la synchro rejouable : sans elle, chaque nuit recréerait 75 doublons.
  • Rien n'est jamais supprimé. Une recette qui disparaît d'Inpulse ou passe inactive est marquée Statut = Archivée.
  • Le schéma de la base est lu d'abord. Seules les colonnes qui existent vraiment sont écrites, avec ou sans accents. Ajouter ou retirer une colonne dans Notion ne casse pas la synchro.
  • La règle des GATEAU est reprise telle quelle : vendus à la part, leur coût matière Inpulse porte sur le gâteau entier, donc divisé par 8 — comme sur la page Suivi Food Cost.

Aucun secret ne part dans le dépôt

tfb-achats est un dépôt public. Le code ne contient aucune clé : API_KEY, NOTION_TOKEN et NOTION_DB_RECETTES sont lus dans les variables d'environnement Netlify.

01 Les fichiers

racine du dépôt / sync-recettes-core.js 
// Synchronisation Inpulse -> Notion du catalogue de recettes.
//
// Source  : GET https://api.inpulse.ai/public/v2/products (pagine, 100 par appel),
//           on ne garde que entityType === "recipe" et status === "active".
// Cible   : une base de donnees Notion, une page par recette.
// Cle      : la propriete texte "ID Inpulse" porte l'id Inpulse. C'est elle qui
//            rend la synchro idempotente : on met a jour la page existante au
//            lieu d'en creer une deuxieme.
//
// Aucun secret n'est ecrit ici : tout vient des variables d'environnement
// Netlify (API_KEY, NOTION_TOKEN, NOTION_DB_RECETTES).
//
// La fonction n'ecrit dans Notion que les proprietes qui existent reellement
// dans la base : on lit d'abord son schema. Ajouter ou retirer une colonne
// dans Notion ne casse donc pas la synchro.

const INPULSE_BASE = "https://api.inpulse.ai";
const NOTION_API = "https://api.notion.com/v1";
const NOTION_VERSION = "2022-06-28";

// Noms de colonnes attendus dans Notion. Toute colonne absente est ignoree.
const P = {
  id: "ID Inpulse",
  categorie: "Categorie",
  sousCategorie: "Sous-categorie",
  sku: "SKU",
  prixTTC: "Prix TTC",
  prixHT: "Prix HT",
  cout: "Cout matiere",
  foodCost: "Food cost",
  statut: "Statut",
  synchro: "Derniere synchro",
};

const sleep = (ms) => new Promise((r) => setTimeout(r, ms));

// ---------------------------------------------------------------- Inpulse

async function fetchRecipes(apiKey) {
  const out = [];
  let skip = 0;
  let total = Infinity;
  let guard = 0;

  while (skip < total && guard < 100) {
    guard += 1;
    const url = `${INPULSE_BASE}/public/v2/products?skip=${skip}&limit=100`;
    const r = await fetch(url, {
      method: "GET",
      headers: { "x-api-key": apiKey, Accept: "application/json" },
    });
    if (!r.ok) throw new Error(`Inpulse ${r.status} sur ${url}: ${await r.text()}`);

    const d = await r.json();
    const items = Array.isArray(d.data) ? d.data : [];
    total = Number(d.total) || 0;

    for (const p of items) {
      if (p.entityType !== "recipe" || p.status !== "active") continue;
      if (p.priceWithTaxes == null || p.costWithoutTaxesOnSite == null) continue;

      const priceHT = p.priceWithTaxes / (1 + (Number(p.vatRate) || 0) / 100);
      // Meme convention que la page Suivi Food Cost : un GATEAU est vendu a la
      // part, son cout matiere Inpulse porte sur le gateau entier (8 parts).
      const isGateau8 = /GATEAU/i.test(p.name || "");
      const cost = isGateau8 ? p.costWithoutTaxesOnSite / 8 : p.costWithoutTaxesOnSite;

      out.push({
        id: String(p.id),
        name: String(p.name || "").trim() || "(sans nom)",
        categorie: p.category || "AUTRE",
        sousCategorie: p.subCategory || null,
        sku: p.sku ? String(p.sku) : null,
        prixTTC: round2(p.priceWithTaxes),
        prixHT: round2(priceHT),
        cout: round2(cost),
        foodCost: priceHT > 0 ? cost / priceHT : null, // ratio, ex 0.242
        adj8: isGateau8,
      });
    }

    if (items.length === 0) break;
    skip += items.length;
    if (items.length < 100) break;
  }

  return out;
}

function round2(v) {
  const n = Number(v);
  return Number.isFinite(n) ? Math.round(n * 100) / 100 : null;
}

// ----------------------------------------------------------------- Notion

async function notion(token, path, opts = {}) {
  const r = await fetch(`${NOTION_API}${path}`, {
    ...opts,
    headers: {
      Authorization: `Bearer ${token}`,
      "Notion-Version": NOTION_VERSION,
      "Content-Type": "application/json",
      ...(opts.headers || {}),
    },
  });
  const text = await r.text();
  let body;
  try {
    body = JSON.parse(text);
  } catch {
    body = { raw: text };
  }
  if (!r.ok) {
    const msg = body && body.message ? body.message : text;
    throw new Error(`Notion ${r.status} sur ${path}: ${msg}`);
  }
  return body;
}

// Rapprochement des noms de colonnes insensible aux accents, a la casse et aux
// espaces : "Categorie", "Catégorie" et "categorie" designent la meme colonne.
// Sans cela, un accent oublie cote Notion ferait silencieusement disparaitre
// une donnee de la synchro.
function normalize(s) {
  return String(s || "")
    .normalize("NFD")
    .replace(/[\u0300-\u036f]/g, "")
    .toLowerCase()
    .replace(/\s+/g, " ")
    .trim();
}

async function loadSchema(token, dbId) {
  const db = await notion(token, `/databases/${dbId}`);
  const props = db.properties || {};
  const titleKey = Object.keys(props).find((k) => props[k].type === "title");
  if (!titleKey) throw new Error("Base Notion sans propriete de type titre.");

  // Nom attendu (sans accents) -> nom reel dans la base.
  const alias = {};
  for (const real of Object.keys(props)) alias[normalize(real)] = real;

  return { props, titleKey, alias };
}

// Resout un nom attendu vers la colonne reelle, si elle existe et a le bon type.
function resolve(schema, wanted, type) {
  const real = schema.alias[normalize(wanted)];
  if (!real) return null;
  const p = schema.props[real];
  if (!p) return null;
  if (type && p.type !== type) return null;
  return real;
}

// Toutes les pages de la base, indexees par ID Inpulse.
async function loadExisting(token, dbId, idKey) {
  const byId = new Map();
  const orphans = [];
  let cursor;

  do {
    const body = { page_size: 100 };
    if (cursor) body.start_cursor = cursor;
    const page = await notion(token, `/databases/${dbId}/query`, {
      method: "POST",
      body: JSON.stringify(body),
    });

    for (const row of page.results || []) {
      const key = plainText((row.properties || {})[idKey]);
      if (key) byId.set(key, row.id);
      else orphans.push(row.id);
    }

    cursor = page.has_more ? page.next_cursor : null;
  } while (cursor);

  return { byId, orphans };
}

function plainText(prop) {
  if (!prop) return null;
  const arr = prop.rich_text || prop.title;
  if (!Array.isArray(arr) || !arr.length) return null;
  return arr.map((t) => t.plain_text || "").join("").trim() || null;
}

// Ne construit que les proprietes presentes dans le schema de la base.
function buildProps(recipe, schema, nowIso) {
  const out = {};
  out[schema.titleKey] = { title: [{ text: { content: recipe.name.slice(0, 2000) } }] };

  const setText = (wanted, value) => {
    const k = resolve(schema, wanted, "rich_text");
    if (k) out[k] = { rich_text: value ? [{ text: { content: String(value) } }] : [] };
  };
  const setSelect = (wanted, value) => {
    const k = resolve(schema, wanted, "select");
    if (k) out[k] = { select: value ? { name: String(value) } : null };
  };
  const setNumber = (wanted, value) => {
    const k = resolve(schema, wanted, "number");
    if (k) out[k] = { number: value == null ? null : value };
  };

  setText(P.id, recipe.id);
  setText(P.sku, recipe.sku);
  setSelect(P.categorie, recipe.categorie);
  setSelect(P.sousCategorie, recipe.sousCategorie);
  setNumber(P.prixTTC, recipe.prixTTC);
  setNumber(P.prixHT, recipe.prixHT);
  setNumber(P.cout, recipe.cout);

  const fcKey = resolve(schema, P.foodCost, "number");
  if (fcKey) {
    // Colonne formatee en pourcentage : Notion attend le ratio (0,242 -> 24,2 %).
    // Colonne numerique simple : on ecrit la valeur en points de pourcentage.
    const isPercent = schema.props[fcKey].number && schema.props[fcKey].number.format === "percent";
    const v = recipe.foodCost;
    out[fcKey] =
      v == null
        ? { number: null }
        : { number: isPercent ? Math.round(v * 10000) / 10000 : Math.round(v * 1000) / 10 };
  }

  setSelect(P.statut, "Active");

  const dKey = resolve(schema, P.synchro, "date");
  if (dKey) out[dKey] = { date: { start: nowIso } };

  return out;
}

// ------------------------------------------------------------------- sync

async function syncRecettes(env) {
  const apiKey = env.API_KEY;
  const token = env.NOTION_TOKEN;
  const dbId = env.NOTION_DB_RECETTES;

  const missing = [];
  if (!apiKey) missing.push("API_KEY");
  if (!token) missing.push("NOTION_TOKEN");
  if (!dbId) missing.push("NOTION_DB_RECETTES");
  if (missing.length) throw new Error(`Variables d'environnement manquantes : ${missing.join(", ")}`);

  const nowIso = new Date().toISOString();
  const recipes = await fetchRecipes(apiKey);
  const schema = await loadSchema(token, dbId);

  const idKey = resolve(schema, P.id, "rich_text");
  if (!idKey) {
    throw new Error(
      `La base Notion doit contenir une propriete de type Texte nommee "${P.id}" : ` +
        `c'est la cle de rapprochement, sans elle chaque synchro creerait des doublons.`
    );
  }

  const { byId } = await loadExisting(token, dbId, idKey);

  let created = 0;
  let updated = 0;
  const errors = [];
  const seen = new Set();

  for (const r of recipes) {
    seen.add(r.id);
    const properties = buildProps(r, schema, nowIso);
    const pageId = byId.get(r.id);
    try {
      if (pageId) {
        await notion(token, `/pages/${pageId}`, {
          method: "PATCH",
          body: JSON.stringify({ properties }),
        });
        updated += 1;
      } else {
        await notion(token, "/pages", {
          method: "POST",
          body: JSON.stringify({ parent: { database_id: dbId }, properties }),
        });
        created += 1;
      }
    } catch (e) {
      errors.push(`${r.name} (${r.id}) : ${e.message}`);
    }
    await sleep(350); // Notion tolere ~3 requetes/seconde
  }

  // Recettes disparues d'Inpulse ou passees inactives : on ne supprime rien,
  // on les marque, ce qui suffit a les sortir des listes de choix filtrees.
  let archived = 0;
  const statutKey = resolve(schema, P.statut, "select");
  if (statutKey) {
    for (const [id, pageId] of byId.entries()) {
      if (seen.has(id)) continue;
      try {
        await notion(token, `/pages/${pageId}`, {
          method: "PATCH",
          body: JSON.stringify({ properties: { [statutKey]: { select: { name: "Archivee" } } } }),
        });
        archived += 1;
      } catch (e) {
        errors.push(`archivage ${id} : ${e.message}`);
      }
      await sleep(350);
    }
  }

  return {
    ok: errors.length === 0,
    at: nowIso,
    recettesInpulse: recipes.length,
    creees: created,
    misesAJour: updated,
    archivees: archived,
    erreurs: errors.slice(0, 20),
  };
}

module.exports = { syncRecettes, fetchRecipes, PROPS: P };

netlify/functions/ sync-recettes-now.js 
// Declenchement manuel de la meme synchro, pour tester sans attendre la nuit.
//
//   curl -X POST https://tfb-achats.netlify.app/api/sync-recettes-now \
//        -H "x-sync-token: <valeur de SYNC_TOKEN>"
//
// Tant que SYNC_TOKEN n'est pas defini dans Netlify, l'endpoint refuse tout :
// pas de porte ouverte par defaut.

const { syncRecettes } = require("../../sync-recettes-core.js");

exports.handler = async (event) => {
  const headers = { "Content-Type": "application/json" };

  if (event.httpMethod !== "POST") {
    return { statusCode: 405, headers, body: JSON.stringify({ error: "Method not allowed" }) };
  }

  const expected = process.env.SYNC_TOKEN;
  if (!expected) {
    return {
      statusCode: 403,
      headers,
      body: JSON.stringify({ error: "SYNC_TOKEN non configure : declenchement manuel desactive." }),
    };
  }

  const given = event.headers["x-sync-token"] || event.headers["X-Sync-Token"];
  if (given !== expected) {
    return { statusCode: 403, headers, body: JSON.stringify({ error: "Jeton invalide." }) };
  }

  try {
    const res = await syncRecettes(process.env);
    return { statusCode: 200, headers, body: JSON.stringify(res) };
  } catch (err) {
    return { statusCode: 500, headers, body: JSON.stringify({ ok: false, erreur: err && err.message }) };
  }
};

03 L'intégration

  • Sur notion.so/my-integrations, créez une intégration interne. Notez son secret, il commence par ntn_.
  • Ouvrez la base Recettes TFB, menu ··· → Connexions → ajoutez l'intégration.
  • Récupérez l'identifiant de la base : dans l'URL de la base en pleine page, c'est la suite de 32 caractères avant le ?.

L'oubli classique

Un token valide sur une base non partagée avec l'intégration donne une erreur 404 object_not_found, pas une erreur de droits. Si vous voyez un 404, c'est l'étape « Connexions » qui manque, neuf fois sur dix.

Si ça coince

404 object_not_found
La base n'est pas partagée avec l'intégration, ou l'identifiant de base est faux. Vérifiez d'abord les Connexions de la base.
La base double à chaque passage
La colonne ID Inpulse est absente, mal typée (Sélection au lieu de Texte), ou a été vidée à la main. La fonction refuse normalement de démarrer dans ce cas et le dit dans les logs.
Un food cost à 2 390 %
La colonne Food cost est en Nombre simple alors que vous attendiez un pourcentage, ou l'inverse. Changez le format dans Notion et relancez : le code s'adapte au format qu'il trouve.
Statut « Archivee » sans accent
C'est voulu, le dépôt s'écrit sans accents. Renommez l'option dans Notion si vous préférez ; la synchro recréera l'option sans accent au prochain archivage, donc gardez les deux ou laissez tel quel.
Rien ne se passe à 4 h
Vérifiez que netlify.toml contient bien le bloc [functions."sync-notion-recettes"] et que le nom correspond exactement au nom de fichier, sans l'extension.
